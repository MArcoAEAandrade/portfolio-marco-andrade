Mais do que uma página para apresentar experiências, este projeto foi criado para **centralizar minha trajetória, meu processo de aprendizado e os projetos que venho desenvolvendo ao longo da minha formação e carreira**.

Aqui estão reunidos:

- experiências de pesquisa;
- serviços que posso oferecer;
- ferramentas e tecnologias que venho aprendendo;
- minha evolução ao longo do tempo.

O portfólio não representa apenas o que eu já sei fazer, mas também **o que estou construindo e aprendendo**.

## Projetos e Cases

O portfólio reúne projetos acadêmicos, profissionais e autorais desenvolvidos com diferentes abordagens.

Alguns exemplos incluem:

### Diagnóstico de Churn
Análise do comportamento de clientes para identificar padrões associados ao cancelamento, utilizando dados, segmentação e indicadores de engajamento.

**Tecnologias:** Python · SQL · Power BI · Análise de Dados

### Expansão Internacional — Nubank
Análise comparativa de mercados para avaliar oportunidades de expansão internacional, combinando indicadores econômicos, financeiros e comportamentais.

**Metodologias:** Market Intelligence · Análise Quantitativa · Consumer Insights · Estratégia de Entrada

### Inclusão Financeira de Jovens Periféricos
Projeto de Iniciação Científica voltado à investigação do comportamento financeiro, barreiras e acesso a serviços financeiros entre jovens de comunidades periféricas.

**Abordagem:** Pesquisa Quantitativa · Pesquisa Qualitativa · Análise de Comportamento

## Desenvolvimento do portfólio

A construção deste projeto também fez parte do meu processo de aprendizado.

Além das tecnologias utilizadas diretamente no desenvolvimento, utilizei o **Antigravity** como apoio durante a construção e evolução da interface, explorando novas possibilidades de desenvolvimento e organização do projeto.

A ideia não foi apenas criar uma página visualmente agradável, mas utilizar o próprio desenvolvimento do portfólio como uma oportunidade para aprender, testar tecnologias e entender melhor como apresentar projetos de forma mais clara e profissional.

Por isso, este repositório deve continuar evoluindo.

Novos projetos, análises, estudos e melhorias de interface serão adicionados conforme minha trajetória avançar.
